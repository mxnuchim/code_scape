# Code of Conduct

CodeScape adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be welcoming, be kind, assume good intent, and give and accept constructive feedback gracefully. Harassment, insults, personal or political attacks, and publishing others' private information are not acceptable in any project space, including issues, pull requests, discussions and chat.

## Reporting

Report unacceptable behaviour privately to the maintainer through GitHub, using the repository owner's contact details on their profile. Reports are handled confidentially. Maintainers may remove, edit or reject contributions that don't follow this code. They may also temporarily or permanently ban contributors whose behaviour is harmful, following the enforcement guidelines of the Contributor Covenant.
